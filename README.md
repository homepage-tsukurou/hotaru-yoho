- 7月：リョウブ・ハゼノキ
- 8月：カラスザンショウ・コシアブラ

- 10月：セイタカアワダチソウ・コスモス

`index.html`、`style.css`、`script.js` と `images` フォルダを、みとろ養蜂場の `mitolo-apiary` リポジトリへアップロードしてください。画像はスマホ表示が重くならないよう、WebP形式へ軽量化しています。

アップロード前に、画面上部のリポジトリ名が必ず `mitolo-apiary` になっていることを確認してください。
